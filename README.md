 Manziz Café

Manziz Café is a full-stack café management web application built with *React* and *Flask*. The application allows customers to browse the café menu, make table reservations, create accounts, and log in, while administrators can manage café operations through a dashboard.

Features
Customer Features

* Browse the café menu
* View food and drink categories
* Create an account
* Log in securely using JWT authentication
* Make table reservations
* View personal profile information

Admin Features

* Dashboard overview
* View recent reservations
* Manage menu items
* Secure authentication
* Responsive admin interface

Technologies Used
 Frontend

* React
* React Router DOM
* Axios
* React Icons

Backend

* Flask
* Flask SQLAlchemy
* Flask Migrate
* Flask JWT Extended
* Flask CORS
* SQLite
